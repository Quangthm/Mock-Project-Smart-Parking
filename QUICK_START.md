# SMARTPARK - QUICK START ONBOARDING GUIDE

Chào mừng bạn gia nhập dự án **SmartPark Management Platform (SPARK)**!  
Tài liệu này hướng dẫn bạn thiết lập toàn bộ môi trường phát triển tự động chỉ với **1 câu lệnh duy nhất**.

---

## 1. PREREQUISITES

1. **Docker Desktop** (bắt buộc - status màu xanh Engine Running)
2. **PowerShell** (Windows PowerShell 5.1 hoặc PowerShell 7+)
3. **.NET 8.0 SDK** (dành cho Backend Dev)

---

## 2. CÁC BƯỚC THỰC HIỆN SETUP

### **Bước 1: Cấp quyền chạy script trên PowerShell**

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```
