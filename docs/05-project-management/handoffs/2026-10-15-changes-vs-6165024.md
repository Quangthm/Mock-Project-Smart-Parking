## 4. R08: session lifetime, refresh, logout

- Thêm Domain `SessionLifetime`: access 900 giây, refresh inactivity 24 giờ; hạn session tuyệt đối tối đa 7 ngày.
- Thêm `AuthSession.LastRefreshedAt`; chỉ rotation thành công mới cập nhật mốc inactivity. GET thông thường không gia hạn session.
- Rotate dùng compare-and-swap có điều kiện expiry/inactivity/revoked; hai refresh cùng proof chỉ một request thắng. Access token mới bị giới hạn bởi thời gian còn lại của session.
- Rotation và lưu `RotatedSessionProof` cùng transaction. Logout dùng stable session ID để xử lý trường hợp refresh xảy ra sau bước authenticate của logout. Proof cũ chỉ dùng cho revoke, không dùng lại để authenticate/refresh.
- JWT issuance/validation dùng cùng TimeProvider; không nới clock skew để làm test qua.
- Frontend refresh theo nhu cầu khi access sắp hết hạn, gom request refresh đồng thời; bỏ timer xóa session chỉ vì access token hết hạn và không dùng refresh timer để duy trì idle session.
- Logout chờ rotation của đúng login. Generation fence kiểm tra trước/sau các bước async để mutation, logout, response MFA hoặc response login cũ không tác động lên phiên đăng nhập mới.
- Activation proof trả 401 không xóa một session độc lập đang đăng nhập. Lỗi mạng refresh không tự retry mù hoặc xóa cặp token ngay.

## 6. RabbitMQ, outbox/inbox và SignalR

- Thêm contract `OperatorAccessChanged` có event ID, schema version, aggregate/version, operation ID, actor, tenants và status.
- Outbox được lưu cùng transaction create/activate; worker claim với lease và `FOR UPDATE SKIP LOCKED`, publish ngoài DB transaction, đánh dấu hoàn tất theo lease.
- Consumer deduplicate bằng inbox event ID; projection chỉ áp dụng version mới hơn, chống event trùng/đến sai thứ tự.
- Hub `/hubs/operators` yêu cầu Owner hiện tại; kiểm tra session/scope khi connect, reload và notify. Token hết hạn thì đóng connection. Query-string access token chỉ được nhận ở hub path.
- Push `OperatorsChanged` không mang payload tenant; FE gọi API để lấy lại dữ liệu có authorization. Reconnect reload danh sách; timer retry được dọn, không start connection đang Connected.
- Create callback xử lý idempotent theo Operator ID để response create đến sau live reload không tạo dòng trùng hoặc ghi đè trạng thái mới hơn.
