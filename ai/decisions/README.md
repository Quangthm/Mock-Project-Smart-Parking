# AI Development Decisions

Use this folder for individual decisions specifically about AI-assisted development, AI service boundaries, agent responsibilities, prompts, or AI implementation strategy.

Do not duplicate general business decisions already maintained in the canonical SRS/BA/architecture records.

## Suggested filename

```text
smartpark-ai-decision-<topic>-v1.0.md
```

## Important distinction

A decision record may document an AI development decision, but it must not silently override the canonical requirements baseline.
